The Problem

Whitefish wants clean power for a neighborhood grid. How many solar systems and geothermal units should it buy?

The Inequalities

Budget: 30000x + 50000y ≤ 200000
Do not spend more than $200,000.

Energy: 1100x + 1500y ≥ 6000
Make at least 6,000 kWh each month.

x ≥ 0 and y ≥ 0. You cannot buy a negative amount.

x and y are whole numbers. You cannot buy part of a system.

Summary + Conclusion

Whitefish needs at least 6,000 kWh a month and cannot spend more than $200,000.

(5, 1) gives the most energy. (6, 0) also works and costs $20,000 less. We choose (5, 1) because geothermal helps in winter.

7,000 × 42 g is about 0.3 metric tons. The same 7,000 kWh from a coal plant is about 7.3 metric tons of CO₂.

Code: the inequalities

Copied from planner.js. x is how many 10 kW solar systems. y is geothermal units. Cost and energy use these constants; the button only picks 5 and 1.

const SOLAR_COST = 30000;     // dollars per solar system (10 kW)
const SOLAR_ENERGY = 1100;    // kWh per month per solar system
const GEO_COST = 50000;       // dollars per geothermal unit
const GEO_ENERGY = 1500;      // kWh per month per geothermal unit
const BUDGET = 200000;        // max dollars we can spend
const ENERGY_GOAL = 6000;     // min kWh per month we need

function totalCost(x, y)   { return SOLAR_COST * x + GEO_COST * y; }
function totalEnergy(x, y) { return SOLAR_ENERGY * x + GEO_ENERGY * y; }

// Budget: 30000x + 50000y ≤ 200000
function inBudget(x, y)    { return totalCost(x, y) <= BUDGET; }
// Energy: 1100x + 1500y ≥ 6000
function enoughEnergy(x, y) { return totalEnergy(x, y) >= ENERGY_GOAL; }
function isFeasible(x, y)  { return inBudget(x, y) && enoughEnergy(x, y); }

recommendBtn.addEventListener("click", function () {
  solarSlider.value = 5;
  geoSlider.value = 1;
  update();
});

Code: stacks and the wheel

Copied from decideWheel in deck-nav.js. A vertical scroll moves inside the stack. It does not skip sideways. A sideways scroll changes sections. Scrolling a code box or the Google Sheet is left alone.

function decideWheel(input) {
  if (!input || input.uiOpen || input.scrollable) return "ignore";
  var deltaX = input.deltaX || 0;
  var deltaY = input.deltaY || 0;
  var routes = input.routes || {};
  var absX = Math.abs(deltaX);
  var absY = Math.abs(deltaY);
  if (Math.max(absX, absY) < WHEEL_THRESHOLD) return "ignore";
  // Vertical wheel moves down or up inside the current stack.
  // It does not jump to the next horizontal section.
  if (absY >= absX) {
    if (deltaY > 0 && routes.down) return "down";
    if (deltaY < 0 && routes.up) return "up";
    return "ignore";
  }
  if (deltaX > 0 && routes.right) return "right";
  if (deltaX < 0 && routes.left) return "left";
  return "ignore";
}
