The Problem

Whitefish wants clean power for a neighborhood grid. How many of each unit should it buy?

VariableUnitCostEnergy
xSolar$30,0001,100 kWh/mo

Budget: $200,000 · Goal: at least 6,000 kWh/month

The Inequalities

Budget: 30000x + 50000y ≤ 200000
spend no more than $200k

Energy: 1100x + 1500y ≥ 6000
make at least 6,000 kWh each month

Also: x ≥ 0, y ≥ 0, whole numbers only
